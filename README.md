# Kassem's Lounge — website

A website for **Kassem's Lounge**, a family-run Moroccan restaurant in Hemel Hempstead, Hertfordshire ("A Taste of Morocco in the Heart of Hemel"). Client project by MIG Labs.

- **Location:** Hemel Hempstead (opposite the Water Gardens), Hertfordshire, England
- **Phone:** (01442) 954333
- **Cuisine:** Moroccan — tagines, couscous, Moroccan breakfasts, mint tea; family-run; delivery available

## Status
`index.html` is a self-contained static site (single file, no build step, no external requests). Open it in a browser or deploy to any static host (Cloudflare Pages / Netlify / Vercel).

> ⚠️ Menu items, prices and exact opening hours are **placeholders to confirm with the client**. Food photography slots into the marked image areas for production.
